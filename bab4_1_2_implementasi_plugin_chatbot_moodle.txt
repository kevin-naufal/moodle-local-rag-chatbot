4.1.2 Implementasi Plugin Chatbot pada Moodle

Subbab ini menjelaskan implementasi plugin chatbot yang diintegrasikan pada Moodle sebagai antarmuka utama pengguna dalam berinteraksi dengan sistem chatbot pembelajaran. Plugin ini digunakan untuk menyediakan fitur percakapan antara pengguna dan sistem, sehingga pengguna dapat mengajukan pertanyaan terkait materi pembelajaran secara langsung melalui lingkungan Moodle. Dengan adanya integrasi ini, chatbot tidak berjalan sebagai aplikasi terpisah, melainkan menjadi bagian dari sistem pembelajaran yang digunakan oleh pengguna.

Implementasi plugin chatbot pada Moodle berfungsi sebagai penghubung antara pengguna dan backend pemrosesan jawaban. Pengguna dapat membuka halaman chatbot melalui Moodle, kemudian memasukkan pertanyaan pada kolom input yang tersedia. Pertanyaan tersebut dikirimkan ke backend untuk diproses menggunakan model LLM atau mekanisme Retrieval-Augmented Generation (RAG), sesuai dengan mode pemrosesan yang digunakan. Setelah jawaban dihasilkan, sistem mengirimkan kembali respons tersebut ke halaman chatbot agar dapat ditampilkan kepada pengguna.

Tampilan utama plugin berupa halaman conversation chatbot. Pada tampilan ini, pengguna dapat melihat riwayat percakapan, memasukkan pertanyaan baru, dan membaca jawaban yang diberikan oleh sistem. Format percakapan digunakan agar interaksi antara pengguna dan chatbot lebih mudah dipahami, karena pertanyaan dan jawaban ditampilkan secara berurutan dalam satu halaman. Tampilan conversation chatbot yang diimplementasikan pada Moodle ditunjukkan pada Gambar 4.X.

[Gambar 4.X Tampilan Conversation Chatbot pada Moodle]

Berdasarkan Gambar 4.X, halaman chatbot terdiri atas area percakapan, kolom input pertanyaan, dan area tampilan jawaban. Area percakapan digunakan untuk menampilkan interaksi yang terjadi antara pengguna dan chatbot. Kolom input digunakan oleh pengguna untuk memasukkan pertanyaan, sedangkan jawaban yang dihasilkan sistem ditampilkan kembali pada area percakapan. Dengan rancangan tersebut, pengguna dapat mengikuti alur tanya jawab secara langsung tanpa perlu berpindah dari halaman Moodle.

Alur penggunaan plugin chatbot dimulai ketika pengguna membuka halaman chatbot pada Moodle. Setelah itu, pengguna mengetikkan pertanyaan yang berkaitan dengan materi pembelajaran. Sistem kemudian mengirimkan pertanyaan tersebut ke backend untuk diproses. Pada mode LLM-only, backend meneruskan pertanyaan langsung ke model LLM. Pada mode RAG, backend terlebih dahulu melakukan pencarian konteks dokumen yang relevan sebelum menyusun prompt dan memanggil model LLM. Jawaban yang dihasilkan kemudian dikirimkan kembali ke plugin chatbot dan ditampilkan pada halaman conversation.

Implementasi plugin chatbot ini mendukung proses evaluasi sistem karena jawaban dapat dihasilkan melalui beberapa mode pemrosesan, yaitu LLM-only, RAG-BERT, dan RAG-MSMARCO. Meskipun mode pemrosesan dijalankan pada sisi backend, plugin chatbot tetap berperan sebagai titik interaksi utama antara pengguna dan sistem. Dengan demikian, plugin ini menjadi komponen penting dalam menghubungkan lingkungan Moodle dengan sistem chatbot berbasis LLM dan RAG yang dikembangkan pada penelitian ini.
